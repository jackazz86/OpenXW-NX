# Nintendo Switch port branch

This branch of the OpenXW fork adds a Nintendo Switch port layer on top of
[elyosh/OpenXW](https://github.com/elyosh/OpenXW), together with the matching
branch of the [Aeron fork](https://github.com/jackazz86/Aeron/tree/switch).

- No game data and no compiled binaries are distributed here. A legally owned copy
  of *X-Wing* is required; the build artifact is for the owner's own use.
- The build workflow (`.github/workflows/switch.yml`) uses the NroForge SDK, which it
  downloads from its own repository.
- All credit for OpenXW, Aeron, landru and iMUSE goes to their author.
